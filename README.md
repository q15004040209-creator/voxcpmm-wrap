## 🌟 项目简介 / Project Overview

`voxcpmm-wrap` 是 **VoxCPM2** 的 Python 封装库，提供了简洁易用的接口来实现多语言语音合成、创意声音设计与语音克隆。

`voxcpmm-wrap` is a Python wrapper for **VoxCPM2**, providing clean interfaces for multilingual TTS, creative voice design, and voice cloning.

### 核心特性 / Key Features

| 特性 / Feature | 说明 / Description |
|---|---|
| 🌍 **30 种语言** / 30 Languages | 无需语言标签，直接输入任意语言文本 / No language tag needed |
| 🎨 **声音设计** / Voice Design | 从自然语言描述生成全新声音 / Create brand-new voices from text descriptions |
| 🎙️ **可控克隆** / Controllable Cloning | 参照音频克隆，保留音色同时调控风格 / Clone voice with style control |
| 🔁 **极致克隆** / Ultra Cloning | 提供音频+转写文本，逐音素级克隆 / Phoneme-level cloning with transcript |
| 🎧 **48kHz 高保真** / Studio Quality | 直接输出 48kHz 母带级音频 / Native 48kHz studio-quality output |
| ⚡ **流式推理** / Streaming | RTX 4090 上 ~0.13x 实时 / ~0.13x RT on RTX 4090 |
| 🛠️ **灵活微调** / Fine-tuning | LoRA / SFT 两种微调方式 / LoRA & SFT fine-tuning |

## 🚀 快速开始 / Quick Start

### 1. 文本转语音 / Text-to-Speech

```python
from voxcpmm_wrap import VoxCPMWrap
import soundfile as sf

model = VoxCPMWrap.from_pretrained(
    "openbmb/VoxCPM2",
    load_denoiser=False,
)

wav = model.generate(
    text="VoxCPM2 is the current recommended release for realistic multilingual speech synthesis.",
    cfg_value=2.0,
    inference_timesteps=10,
)
sf.write("demo.wav", wav, model.tts_model.sample_rate)
print("Saved: demo.wav")
```

### 2. 声音设计（无需参考音频）/ Voice Design (No Reference Audio)

用自然语言描述创造全新声音（性别、年龄、语调、情感等）：

```python
wav = model.generate(
    text="(A young woman, gentle and sweet voice)Hello, welcome to VoxCPM!",
    cfg_value=2.0,
    inference_timesteps=10,
)
sf.write("voice_design.wav", wav, model.tts_model.sample_rate)
```

### 3. 可控语音克隆 / Controllable Voice Cloning

上传参考音频，克隆音色并可调控速度、情感、风格：

```python
wav = model.generate(
    text="This is a cloned voice generated by VoxCPM2.",
    reference_wav_path="path/to/voice.wav",
)
sf.write("clone.wav", wav, model.tts_model.sample_rate)

# 风格控制 / Style control
wav = model.generate(
    text="(slightly faster, cheerful tone)This is a cloned voice with style control.",
    reference_wav_path="path/to/voice.wav",
    cfg_value=2.0,
    inference_timesteps=10,
)
sf.write("controllable_clone.wav", wav, model.tts_model.sample_rate)
```

### 4. 极致克隆（音频 + 转写）/ Ultra Cloning (Audio + Transcript)

同时提供参考音频和其转写文本，实现逐音素级完美克隆：

```python
wav = model.generate(
    text="This is an ultra cloning demonstration using VoxCPM2.",
    prompt_wav_path="path/to/voice.wav",
    prompt_text="The transcript of the reference audio.",
    reference_wav_path="path/to/voice.wav",  # optional, for better similarity
)
sf.write("ultra_clone.wav", wav, model.tts_model.sample_rate)
```

### 5. 流式推理 / Streaming API

```python
import numpy as np

chunks = []
for chunk in model.generate_streaming(
    text="Streaming text to speech is easy with VoxCPM!",
):
    chunks.append(chunk)

wav = np.concatenate(chunks)
sf.write("streaming.wav", wav, model.tts_model.sample_rate)
```

## 🛠️ CLI 使用 / CLI Usage

```bash
# 声音设计（无需参考音频）
voxcpmm-wrap design \
  --text "VoxCPM2 brings studio-quality multilingual speech synthesis." \
  --output out.wav

# 可控克隆（风格控制）
voxcpmm-wrap design \
  --text "VoxCPM2 brings studio-quality multilingual speech synthesis." \
  --control "Young female voice, warm and gentle, slightly smiling" \
  --output out.wav

# 语音克隆（参考音频）
voxcpmm-wrap clone \
  --text "This is a voice cloning demo." \
  --reference-audio path/to/voice.wav \
  --output out.wav

# 极致克隆（提示音频 + 转写）
voxcpmm-wrap clone \
  --text "This is a voice cloning demo." \
  --prompt-audio path/to/voice.wav \
  --prompt-text "reference transcript" \
  --reference-audio path/to/voice.wav \
  --output out.wav

# 批量处理
voxcpmm-wrap batch --input examples/input.txt --output-dir outputs

# 帮助
voxcpmm-wrap --help
```
